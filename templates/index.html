Passo a passo

Como rodar o projeto e como usar cada botão. Em Python não existe compilação: basta executar o app.py.

1. Como rodar o projeto

Faça uma vez; depois é só executar o app.

1

Instalar o Python 3.12

Baixe em python.org e, no instalador, marque Add python.exe to PATH. Prefira o 3.12: versões muito novas (3.15) não têm pacotes prontos para o SDK da OCI e dão erro de compilação.

py -3.12 --version

Deve aparecer Python 3.12.x.

2

Abrir o terminal na pasta do projeto

No PowerShell, entre na pasta onde estão o app.py e a pasta templates:

cd "C:\Users\SEU-USUARIO\Desktop\filaOCI"
3

Instalar as dependências

py -3.12 -m pip install -r requirements.txt

Instala o Flask, o SDK da OCI e o requests.

4

Gerar a chave de API na OCI

  • No console da OCI, clique no seu perfil (canto superior direito) e abra My profile.
  • Vá em API keys → Add API key → deixe Generate API key pair.
  • Clique em Download private key (o .pem) e depois em Add.
  • Copie o texto da janela Configuration file preview.
O .pem só pode ser baixado nessa hora. Guarde-o bem e não envie para ninguém nem para o GitHub.
5

Criar a pasta .oci do projeto

Dentro do projeto, crie a pasta .oci com o arquivo config (sem extensão, é o texto copiado) e o seu chave.pem. No config, deixe o key_file com o caminho real do .pem:

[DEFAULT] user=ocid1.user.oc1..xxxx fingerprint=xx:xx:xx:xx... tenancy=ocid1.tenancy.oc1..xxxx region=us-phoenix-1 key_file=C:/Users/SEU-USUARIO/Desktop/filaOCI/.oci/chave.pem
Use barras normais / no caminho e apague o texto <path to your private keyfile> e o # TODO.
6

Criar o arquivo .env

Na pasta do projeto, crie o .env. O OCID e o endpoint estão na página de detalhes da sua fila, em Serviços ao Desenvolvedor → Filas.

OCI_CONFIG_FILE=C:/Users/SEU-USUARIO/Desktop/filaOCI/.oci/config OCI_QUEUE_ID=ocid1.queue.oc1.phx.xxxxxxxx OCI_QUEUE_ENDPOINT=https://cell-1.queue.messaging.us-phoenix-1.oci.oraclecloud.com OCI_QUEUE_CHANNEL=canal1
A região do config e a do endpoint da fila precisam ser a mesma. Não precisa configurar e-mail: o envio vem desligado.
7

Executar o app

py -3.12 app.py

Quando aparecer Running on http://127.0.0.1:3000, abra localhost:3000. Para parar, use Ctrl + C no terminal.

2. Como usar o aplicativo

Publicar manda para a fila na OCI; consumir lê, mostra na tela e remove da fila.

1

Publicar uma mensagem

No card Produtor, preencha o e-mail (pode ser qualquer texto, nada é enviado) e a mensagem. Clique em Publicar. Uma notificação confirma que foi inserida na fila.

2

Conferir na OCI (opcional)

No console, abra a sua fila e use a opção de sondar mensagens. A mensagem publicada deve aparecer lá.

3

Consumir

No card Consumidor, clique em Consumir. As mensagens da fila aparecem na tela e são apagadas da OCI. Mensagens simples criadas pelo botão Enviar mensagem do console também funcionam.

Se a fila tiver retenção de 1 minuto, mensagens não consumidas nesse tempo são excluídas pela própria OCI.
4

Usar canais

Publicar – canal marca a mensagem com o canal definido em OCI_QUEUE_CHANNEL (padrão canal1). Consumir – canal lê só as mensagens desse canal, uma por vez. Os botões sem “canal” trabalham com a fila em geral.

5

Se o processamento falhar

A mensagem não é apagada: ela volta para a fila depois de alguns segundos (aviso amarelo na tela). Ao passar do máximo de tentativas de entrega da fila, a OCI a envia para a fila de mensagens inativas (DLQ).

3. Problemas comuns

Os erros aparecem no terminal onde o app está rodando.

python / py não reconhecidoPython não instalado ou sem “Add to PATH”. Reinstale marcando a opção e abra um terminal novo.
Erro ao compilar crc32cVersão nova demais do Python. Instale o 3.12 e use py -3.12 nos comandos.
Could not find config fileCaminho do OCI_CONFIG_FILE errado ou arquivo chamado config.txt. Use o caminho completo no .env.
Variável obrigatória não definidaO .env está fora da pasta do projeto ou sem OCI_QUEUE_ID / OCI_QUEUE_ENDPOINT.
HTTP 401Fingerprint, OCID ou caminho do key_file errados no config.
HTTP 403 / 404OCID da fila errado, endpoint de outra região ou usuário sem permissão na fila.
Mensagens consumidas são removidas da fila na OCI.
